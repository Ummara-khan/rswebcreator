# RS Web Creator - Next.js App

A pixel-perfect replica of rswebcreator.com built with Next.js 14, TypeScript, and Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages

- `/` - Home page (hero, about, services, portfolio, testimonials, brands, CTA)
- `/logo` - Logo Design service page
- `/website` - Web & App Development page
- `/copywriting` - Copywriting service page
- `/animations` - Animations service page
- `/marketing` - Digital Marketing page
- `/portfolio` - Portfolio showcase page
- `/pricing` - Pricing plans page
- `/contact` - Contact form page

## Features

- ✅ Dark theme matching rswebcreator.com exactly (black + lime #c6f135)
- ✅ Fully responsive / mobile-friendly
- ✅ Animated hero with 3D orb and globe dots
- ✅ Floating stat card with keyframe animation
- ✅ Scrolling brand ticker
- ✅ All 9 nav pages implemented
- ✅ WhatsApp floating button
- ✅ Mobile hamburger menu
- ✅ Scroll-triggered fade-up animations (via CSS Intersection Observer)

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Google Fonts (Barlow Condensed, Barlow, Inter)
